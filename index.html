ERP para Inversiones ICR — Módulo de Almacén/Inventario

ERP

Schema PostgreSQL de 18 tablas + 2 vistas. Arquitectura donde un LLM interpreta la intención del usuario → genera un comando JSON estructurado → N8N valida, autoriza y ejecuta en transacción → base de datos → respuesta vía Telegram. El LLM nunca escribe directo sobre tablas de negocio: auditoría completa.

MVP con autenticación JWT + permisos por rol. Entregables: PRD, documento técnico (contratos de API, validaciones, transacciones SQL, códigos de error, diseño N8N) y propuesta comercial. Parte de un ERP modular más amplio, en desarrollo.
